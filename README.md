# Zaheer Nazari — Portfolio

A modern, fully responsive personal portfolio website built to showcase my frontend development skills, services, and projects.

## 🚀 Live Demo
[View the Live Portfolio Here](https://zaheer-commit.github.io/) *(بعد از دیپلوی این لینک فعال می‌شود)*

## 🛠 Tech Stack
* **Framework:** React.js (Bootstrapped with Vite)
* **Language:** TypeScript
* **Styling:** Sass (SCSS)
* **Routing:** React Router DOM
* **Forms:** Formspree API

## ✨ Key Features
* Fully responsive design (Mobile, Tablet, and Desktop views)
* Custom interactive hamburger menu for mobile devices
* Smooth CSS animations, hover effects, and custom UI components
* Functional contact form integrated directly with email
* Clean, scalable folder architecture and BEM naming convention

## 💻 Running Locally
To run this project on your local machine:

1. Clone the repository:
   `git clone https://github.com/zaheer-commit/zaheer-commit.github.io.git`
2. Navigate to the project folder:
   `cd zaheer-commit.github.io`
3. Install dependencies:
   `npm install`
4. Start the development server:
   `npm run dev`
